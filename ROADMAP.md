# OpenForge Roadmap

OpenForge is starting small. This roadmap is a living document: priorities can change as contributors share ideas and the community grows.

## Phase 1 — Set the foundations

- [x] Publish the repository and project overview.
- [x] Add contribution and community guidelines.
- [ ] Invite the first contributors and gather feedback.
- [ ] Agree on the first learning topics and content format.

## Phase 2 — Build useful learning material

- [ ] Publish beginner-friendly programming resources.
- [ ] Create the first software engineering learning path.
- [ ] Add coding challenges with explanations and test cases.
- [ ] Add practical project ideas for different experience levels.

## Phase 3 — Grow collaboration

- [ ] Establish a regular contribution and review rhythm.
- [ ] Add more learning paths based on community interest.
- [ ] Encourage peer reviews and collaborative projects.
- [ ] Improve documentation based on contributor feedback.

## Suggest a direction

Open an issue to suggest a topic, learning path, challenge or project. Explain who it would help and why.
