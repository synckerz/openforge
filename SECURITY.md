# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Instead, use GitHub's **Report a vulnerability** option in the repository's Security tab, if available. If that option is unavailable, contact the repository owner privately through the contact options on their GitHub profile.

Include:
- A clear description of the suspected vulnerability.
- Steps to reproduce it, if known.
- The potential impact.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate before publicly disclosing a vulnerability.

## Scope

OpenForge is an evolving community project. Security reports are welcome for code, examples, documentation or project infrastructure maintained in this repository.
