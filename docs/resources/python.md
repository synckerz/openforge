# Python Learning Resources

A small, beginner-friendly collection of Python resources. You do not need to use all of them: choose one main course, practise regularly, and use the others when you need a different explanation or more exercises.

## Start here

| Resource | Level | What it offers |
| --- | --- | --- |
| [Python for Everybody](https://www.py4e.com/) | Complete beginner | A structured introduction to programming with Python, including free course materials, explanations and exercises. A good first course if you are new to programming. |
| [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) | Beginner | A free, university-style course with lectures, problem sets and a practical approach to Python fundamentals. |
| [Python.org: Getting Started](https://www.python.org/about/gettingstarted/) | Complete beginner | The official Python website's starting point, with guidance on installing Python and finding introductory learning material. |

## Practise and build

| Resource | Level | What it offers |
| --- | --- | --- |
| [Exercism — Python Track](https://exercism.org/tracks/python) | Beginner to intermediate | Short coding exercises with automated feedback and optional community mentoring. Useful for practising one concept at a time. |
| [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) | Beginner | A practical, project-oriented book that teaches Python through everyday automation tasks. The online book is available to read for free. |
| [The Python Tutorial](https://docs.python.org/3/tutorial/) | Beginner with some programming experience | The official language tutorial. It is an excellent reference, but it assumes some basic understanding of programming, so it may not be the easiest first resource for absolute beginners. |

## A simple learning route

1. If programming is completely new to you, begin with **Python for Everybody** or **CS50P**.
2. Write and run the examples yourself rather than only watching or reading.
3. Use **Exercism** to practise each topic.
4. Try a small automation project with **Automate the Boring Stuff**.
5. Keep the official Python tutorial nearby as a reference.

## How to contribute

Found a broken link, a better beginner resource, or a correction? Please open an issue or submit a pull request. When suggesting a resource, include its intended level and explain why it is useful.
