# Contributing to OpenForge

Welcome! OpenForge is built by people learning, sharing and building together. You do not need to be an experienced developer to make a useful contribution.

## Ways to contribute

- Improve explanations, spelling or documentation.
- Share a reliable learning resource (include a short note about why it is useful).
- Suggest a project idea or a coding challenge.
- Reproduce a bug or report an issue with clear steps.
- Write examples, tests or code.
- Review a pull request and offer constructive feedback.

## Before you start

1. Read the [README](README.md) to understand the project.
2. Search existing issues and pull requests to avoid duplicate work.
3. If your change is substantial, open an issue first to discuss the idea.
4. For a small documentation fix, you can usually start directly.

## Pull request workflow

1. Fork this repository.
2. Create a branch with a clear name, such as `docs/add-python-resources`.
3. Make one focused change at a time.
4. Check spelling, links and formatting. If you add code, include suitable tests or explain how you checked it.
5. Commit with a clear message, for example `docs: add beginner Python resources`.
6. Open a pull request and explain **what** changed and **why**.

## Contribution guidelines

- Be respectful, patient and constructive.
- Prefer clear, beginner-friendly explanations.
- Keep contributions focused and easy to review.
- Cite sources and respect licenses when adding external material.
- Do not submit copied tutorials, copyrighted material or AI-generated content without reviewing it for accuracy and originality.
- Never include passwords, API keys, private data or other secrets.

## Unsure where to begin?

Look for issues labelled **good first issue** or **help wanted**. You can also open an issue and ask for guidance. Questions are welcome.

Thank you for helping OpenForge grow!
