# Getting Help

Have a question or need a hand?

- **Usage and learning questions:** Open a GitHub Discussion if Discussions are enabled, or create an issue with the question label.
- **Bug reports:** Use the bug report issue template and include steps to reproduce the problem.
- **Ideas:** Use the feature request template so the community can discuss the idea.
- **Contributing:** Read [CONTRIBUTING.md](CONTRIBUTING.md) and look for beginner-friendly issues.

Before opening a new issue, please check whether someone has already asked the same question.

Be patient and respectful. OpenForge is a community learning project, and people contribute in their available time.
